# CRYPTO UPGRADE — Telegram Mini App

Апгрейд скинов CS2: баланс в рублях, магазин, инвентарь, колесо с шансами 80/75/50/30/10%.

## Запуск
1. Node.js 20+ и PostgreSQL.
2. Создай базу: `createdb -U postgres crypto_upgrade`
3. Схема: `psql -U postgres -d crypto_upgrade -f database.sql` (можно запускать повторно — на старой базе обновит таблицы).
4. `npm install`
5. Скопируй `.env.example` в `.env`, впиши `DATABASE_URL`.
6. **Загрузи скины со Steam (реальные цены в ₽ и картинки):** `npm run import:steam`
   - берутся ВСЕ скины (оружие, ножи, перчатки, включая StatTrak и Souvenir), у которых есть цена. Чтобы отсечь дешёвые, поставь в `.env` `MIN_PRICE_KOPEKS=400` (от 4 ₽);
   - если у тебя уже есть `.env` со старым значением 400 — поменяй на 1;
   - Steam ограничивает частоту запросов, полный импорт занимает 10–30 минут — это нормально;
   - для проверки: `npm run import:steam -- --max 300`;
   - запускай раз в сутки, чтобы цены обновлялись.
7. `npm start` → http://localhost:3000 (не открывай index.html двойным кликом).

`DEV_MODE=true` — вход без Telegram и кнопка «Тестовое пополнение» в окне пополнения. В продакшене: `DEV_MODE=false` и `TELEGRAM_BOT_TOKEN` из @BotFather.

## Подключение к Telegram
1. Размести приложение на HTTPS-домене (Telegram не открывает http).
2. В @BotFather: `/newapp` (или `/mybots` → бот → Bot Settings → Menu Button) и укажи ссылку на сайт.
3. В `.env`: `DEV_MODE=false`, `TELEGRAM_BOT_TOKEN=<токен бота>`.
Приложение само раскрывается на весь экран, красится под тёмную тему, использует кнопку «Назад» и вибрацию Telegram.

## Пополнение криптой
Окно пополнения и кнопка баланса готовы. Не хватает только платёжного провайдера:
в `server.js` реализуй `createDepositInvoice()` и вебхук провайдера, который вызывает
`creditBalance(client, userId, amountCents, 'deposit', 'Пополнение', invoiceId)` — повторный вебхук с тем же `invoiceId` второй раз ничего не зачислит. Подпись вебхука проверяй обязательно.

## Как работает апгрейд
Сервер делает бросок криптографическим генератором (`crypto.randomInt`), вероятность равна выбранному шансу. Стрелка на колесе останавливается в той зоне, которую определил сервер.
